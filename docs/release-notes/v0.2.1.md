**Player names without extracting anything.**

- `--game "<FL27 folder>"` now also finds the player database inside the game's and the mods' `.cpk` files. Before, it only worked with an extracted database in a sider `cpk.root` folder.
- `--pesdb` also accepts a `.cpk` file.
- If no database is found, the PC window says where it looked.

**Downloads**
- Windows: `pesm-coaching-zone-windows-x86_64.exe`
- Linux: `pesm-coaching-zone-linux-x86_64` (run `sudo setcap cap_sys_ptrace+ep <file>` again for the new file)

Read-only: it never changes the game, its files or your saves.
